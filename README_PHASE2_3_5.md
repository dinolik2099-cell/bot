# QuantBot Phase 2.3.5 模型池 V1.1

本版本用于建立第一批模型候选池，并在正式大规模研究之前进行本地预检。

## 本版本重点

- 36 个模型候选
- 统一模型注册表
- 参数网格与 Python 函数签名一致性检查
- 严格因果声明
- 模型输出统一为 `signal / stop / target`
- 合成数据接口测试
- 未来数据敏感性测试
- 中文预检输出

## 重要修正

`price_ema_momentum` 的参数网格包含 `threshold`，因此 V1.1 已将该参数正式纳入模型函数定义，并用于多空动量判断。

## 研究纪律

模型进入正式研究前，必须继续经过：

`TRAIN → VALIDATION → 冻结 → OOS`

ABU 中已有模型实现不等于 QuantBot 已验证有效。

本包不修改现有回测引擎，不替换既有研究边界，不覆盖已有研究结果。
