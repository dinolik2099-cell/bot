# QuantBot 模型候选库

版本：Phase 2.3.5 / V1.0

本目录用于记录 QuantBot 的模型来源、研究依据、实现状态和验证状态。

## 模型准入原则

1. 候选模型不代表有效模型。
2. 有论文或成熟系统实现，不代表在 QuantBot 的 BTC/ETH 等 1H 永续数据上有效。
3. 所有模型必须经过统一 TRAIN → VALIDATION → 冻结 → OOS 流程。
4. 禁止使用 OOS 结果反向选择模型。
5. 禁止只按照收益率最高选择模型。
6. 必须考虑最大回撤、盈利因子、交易次数、稳定性和成本敏感性。
7. 形态模型必须严格证明不存在未来数据。

## 证据等级

| 等级 | 含义 |
|---|---|
| S | 有成熟量化研究依据，且适合作为核心研究方向 |
| A | 有较强研究/工程依据，值得优先测试 |
| B | ABU 等成熟系统已有实际实现，值得独立验证 |
| C | 复杂/主观/实验性较强，暂后置 |
