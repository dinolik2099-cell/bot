# QuantBot Phase 2.4-B V1.3.3

## 本版目的

修正 V1.3.2 压力测试中两个会影响结论可信度的问题，并增加模型级连续亏损质量门槛。

### 1. 成本场景固定基准

手续费和滑点倍率始终相对于固定基准值计算，不允许上一场景修改后的全局值参与下一场景，避免出现成本递归放大。

- 基准手续费：0.04%
- 基准滑点：2 bps
- 手续费×3：0.12%
- 滑点×10：0.20%
- 二者合计单边名义成本压力约 0.32%，往返约 0.64%（未计资金费率）。

### 2. Bootstrap “最差”分位方向修正

- 最终资金：取低分位，越低越差。
- 最低资金：取低分位，越低越差。
- 最大回撤：取高分位，越高越差。
- 最大连续亏损：取高分位，越高越差。

不再出现“最差分位反而比中位数更好”的倒置结果。

### 3. 连续亏损采用模型×交易对质量门槛

组合所有交易的连续亏损不能直接代表某一个模型的质量。因此 V1.3.3 单独统计每个 `Model×Symbol` sleeve 的连续亏损。

判定：

- 0–10：正常
- 11–15：关注
- 16–20：严重关注
- **≥21：不合格**

因此，**26 连亏不再被当成“极端尾部统计”而放过，而是直接标记该 Model×Symbol sleeve 不合格。**

这个门槛不是用 50 连亏之类的极端数字抬杠；它用于淘汰已经表现出明显持续失效特征的模型/交易对组合。

## 研究边界

- 只读取 D-1 冻结参数。
- 只运行 TRAIN / VALIDATION。
- 不读取 D-2、D-3、OOS。
- 不使用 OOS 进行筛选或调参。
- 不按最高收益选模型。
- 本版仍属于最坏情况/生存压力研究，不授权实盘。
